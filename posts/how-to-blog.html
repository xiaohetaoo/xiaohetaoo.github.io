开始使用：三分钟学会往这个博客里写文章

这个博客没有数据库、没有后台，只有几个 HTML 文件。写一篇新文章 = 复制一个模板、改几行字、回首页加一张卡片。

这篇指南本身就是用博客的排版写的，所以它同时是一份排版元素速查表：你会在这里看到标题、列表、代码块、引用、表格的全部效果，写文章时照着抄结构就行。

第一步：复制模板

打开 posts/_template.html，整份复制，重命名成一个英文短横线文件名，比如 my-first-post.html。文件名就是文章的网址，确定后尽量不再改。

第二步：改文章信息

模板里所有待填的地方都用 TODO 标出了，逐个替换：

  • <title> 和 meta description —— 标题与摘要；
  • 正文头部的日期、标签、h1 标题和导语；
  • 文末「上一篇 / 下一篇」指向相邻的文章；

第三步：回首页加一张卡片

打开 index.html，找到 <div class="post-list">，复制一个现成的 <a class="post-card"> 块，把日期、标题、摘要、标签和链接改成新文章的。新卡片放在列表最上面（本站按时间倒序排列）。

正文可以用的排版元素

行内元素

这是加粗，这是链接，这是行内代码 npm run dev。写技术笔记时，命令和文件名都用行内代码包起来，阅读体验会好很多。

代码块（带复制按钮）

把代码贴进 <code> 标签里，同时把同样一段文本填到上方按钮的 data-copy 属性，读者就能一键复制：

            
hello.js

// 注意：代码里的 < 和 & 要写成 &lt; 和 &amp;
function motto() {
  return "把好奇的东西做出来，把做过的东西写下来。";
}
console.log(motto());

列表与引用

  • 无序列表：适合并列的要点；
  • 每行不要太长，一条说一件事；

写作不是把想清楚的东西写下来，而是通过写来想清楚。 —— 这句很适合放在文章结尾。

表格

元素用途示例
h2 / h3小节标题本文的「第一步」「第二步」
pre + code代码块上方 hello.js
blockquote引用金句、摘录
img插图图片放 assets/img/ 后引用

第四步（可选）：本地预览与发布

双击 index.html 就能在浏览器里预览。想发布时，把整个文件夹丢到任意静态托管即可 —— GitHub Pages、Cloudflare Pages、Vercel 都免费，不需要任何构建配置。

就这些。写第一篇时不用想选题，就写「我最近在折腾什么」，写完回来替换掉首页那两篇【占位】，博客就算正式开张了。
